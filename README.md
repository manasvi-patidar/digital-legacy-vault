# Digital Legacy Vault

Digital Legacy Vault is a secure MERN-based platform for creating and managing a digital inheritance plan.

## Planned Features

- User authentication
- Trusted guardians
- Secure digital vault
- Digital will
- Secure document storage
- Dead man's switch
- Emergency verification workflow
- Timed encrypted release
- Audit logs

## Tech Stack

### Frontend

- React
- Vite

### Backend

- Node.js
- Express

### Database

- MongoDB
- Mongoose

### Security

- JWT authentication
- Password hashing
- AES-256-GCM encryption
